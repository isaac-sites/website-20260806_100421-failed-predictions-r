## Introduction

A prediction about unidentified flying objects can only be judged as successful or failed if everyone agrees in advance on what counts as a qualifying sighting. Without that agreement, almost any unusual light, disputed photograph or anecdotal report can be claimed as fulfilment after the fact, making the prediction effectively immune to failure.

For the purpose of testing predictions, the question is not whether an object is extraterrestrial. It is whether a pre-defined event occurred according to agreed rules. Modern scientific and forecasting practice therefore relies on operational definitions: precise criteria that specify what observers must see, where it must happen, how long it must last, what evidence is acceptable, and which ordinary explanations must be excluded before a sighting is counted. NASA's recent work on unidentified anomalous phenomena (UAP) likewise stresses that meaningful investigation depends on high-quality, well-defined observations rather than vague descriptions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

## Why ordinary UFO language creates loopholes

Many UFO predictions use words that sound precise but are actually highly flexible. Terms such as *visible*, *massive*, *public*, *worldwide* or *unexplained* invite disagreement because different readers interpret them differently.

Consider the prediction:

> "A massive UFO will appear publicly over Europe before the end of the year."

Without additional definitions, several questions immediately arise:

* Does "Europe" mean one city or any location on the continent?
* Must the object be visible to the naked eye?
* Does one eyewitness qualify, or are thousands required?
* Is a brief appearance enough?
* Does a later explanation invalidate the prediction?
* Can a disputed online video count?

Because these questions remain unanswered, believers and sceptics can reach opposite conclusions while both claiming to follow the original wording. That makes the prediction difficult—or impossible—to falsify.

A scientifically useful prediction instead removes these interpretive gaps before the deadline arrives.

## How to define visibility, duration and location

A prediction becomes much easier to evaluate when each important element receives an operational definition.

A practical framework might specify:

CriterionExample of a clear definitionVisibilityObservable without specialised equipment by ordinary members of the public.LocationWithin a named city, county or geographic boundary.TimeBetween specific dates and times.DurationRemaining continuously visible for at least 20 minutes.ScaleObservable simultaneously by multiple independent observers across the defined area.DocumentationRecorded by multiple independent photographs, videos or calibrated sensors.VerificationReports from unrelated observers whose accounts substantially agree.

None of these definitions proves that an object is extraordinary. Their purpose is simply to establish whether the predicted event occurred.

Forecasting platforms that evaluate real-world predictions routinely use similar resolution criteria. Questions are written so that the closing date, evidence requirements and later resolution are fixed before events unfold, reducing the opportunity to redefine success retrospectively.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.metaculus.com/faq/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: metaculus.com">[Metaculus]</a><span class="citation-popover" role="note"><span class="citation-popover-source">metaculus.com</span><span class="citation-popover-snippet">Metaculus FAQ...</span></span></span>

## Should an unexplained object be required?

One of the largest sources of disagreement concerns the word *unexplained*.

There are at least three different possibilities:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Initially unidentified.** Observers cannot immediately identify the object.
* **Unexplained after investigation.** Experts examine available evidence and no conventional explanation is established.
* **Permanently unexplained.** No explanation is ever accepted.

</div>

These are very different standards.

Many reported UFO sightings are initially mysterious but later attributed to aircraft, balloons, astronomical objects, drones or optical effects. NASA notes that the limited quality of many observations makes firm conclusions difficult, and that there is currently no evidence linking UAP reports to extraterrestrial technology.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/faqs/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[nasa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP FAQs</span><span class="citation-popover-snippet">NASA ScienceUAP FAQs - NASA Science...</span></span></span>

If a prediction merely requires an object to be unidentified at first glance, it will succeed far more often than one requiring the object to remain unexplained after careful investigation.

Therefore, any falsifiable prediction should specify which definition is intended before the event.

## Public visibility needs measurable thresholds

Predictions often promise a "public" appearance without defining what public means.

Possible measurable standards include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* observed by at least a specified number of unrelated witnesses;
* reported from multiple independent locations;
* visible over a populated area rather than a remote location;
* documented by independent media organisations or public authorities;
* recorded simultaneously by more than one imaging system.

</div>

These thresholds are imperfect, but they are preferable to subjective claims that "many people saw it."

Importantly, media coverage alone should not determine success. News organisations may ignore genuine events or heavily report mistaken ones. The prediction should define the observational event itself rather than relying on publicity afterwards.

## Examples of clear and ambiguous sighting criteria

The contrast between vague and operational wording illustrates why definitions matter.

**Ambiguous prediction**

> "A huge UFO will appear over America."

Problems include:


<div class="content-enhancement content-enhancement--checklist" markdown="1">

* undefined geographic area;
* no deadline beyond the broader prediction period;
* no minimum size;
* no duration;
* no evidence standard;
* no definition of "huge";
* no requirement that ordinary explanations be excluded.

</div>

**Operational prediction**

> "Between 18:00 and 22:00 UTC on 14 October, an unidentified aerial object at least the apparent size of the full Moon will remain visible to the unaided eye for at least 30 consecutive minutes above central London, be independently photographed by at least 100 unrelated observers, and remain without an accepted conventional explanation after investigation."

The second prediction may still prove false, but everyone can judge the outcome using the same criteria.

## Why consistent rules prevent moving the goalposts

Failed UFO predictions are often rescued by changing the definition of success after the deadline.

Common examples include:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* reducing "worldwide" to a single local report;
* accepting blurry photographs after originally implying an obvious public spectacle;
* changing "landing" into a distant light in the sky;
* redefining "public appearance" as a private spiritual experience;
* arguing that governments concealed the event despite the original prediction implying open observation.

</div>

Predetermined sighting rules reduce these opportunities. Once the criteria have been published, later reinterpretation should not change whether the prediction succeeded.

This mirrors broader principles used in empirical science and structured forecasting: hypotheses are evaluated against criteria established before observations are collected, not rewritten afterwards to accommodate unexpected results.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

## The essential rule for testing UFO predictions

A UFO prediction should not be judged by whether people remain convinced that "something happened." It should be judged against pre-agreed observational criteria.

At a minimum, a testable prediction should define:


<div class="content-enhancement content-enhancement--decision" markdown="1">

* what object or event qualifies as the sighting;
* where it must occur;
* when it must occur;
* how long it must remain observable;
* who must be able to observe it;
* what evidence counts;
* whether later conventional explanations invalidate the claim.

</div>

Only when these definitions are fixed before the deadline can a prediction be fairly classified as either fulfilled or failed. Such operational rules do not settle whether UFOs exist; they simply ensure that extraordinary claims are evaluated by consistent, transparent standards rather than changing interpretations after the event.

    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
