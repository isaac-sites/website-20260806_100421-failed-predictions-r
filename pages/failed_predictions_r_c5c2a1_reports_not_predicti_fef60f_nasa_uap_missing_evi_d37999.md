## Introduction

NASA's independent study of unidentified anomalous phenomena (UAP), commonly called UFOs, did not conclude that mysterious reports point to extraterrestrial technology. Instead, it identified a more fundamental problem: many reports simply do not contain enough reliable evidence to support a scientific conclusion. This distinction is important when discussing [failed predictions relating to UFOs]({{ 'failed-predictions-relating-to-ufos/' | relative_url }}). An unresolved report reflects incomplete data, not confirmation of an extraordinary explanation or support for predictions about future events. NASA's study focused on the practical reasons why many sightings remain unresolved and what would be required to investigate them properly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

## The sensor and metadata problems NASA identified

NASA's independent study concluded that the greatest obstacle to understanding UAP is not necessarily the rarity of reports but the poor quality and inconsistency of the available evidence. Most observations were never collected as part of a scientific experiment. Instead, they were chance encounters recorded by cameras, aircraft systems or other sensors that were designed for entirely different purposes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

The report highlights several recurring deficiencies:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **Sensors not designed for UAP observation.** Cameras, radar systems and infrared sensors are generally optimised for navigation, weather monitoring or military operations rather than measuring unknown aerial objects with scientific precision.
* **Missing calibration information.** Without knowing exactly how a sensor behaves under different conditions, investigators cannot determine whether an apparent anomaly reflects a real object or an imaging artefact.
* **Absent metadata.** Critical contextual information—including the sensor model, acquisition time, viewing angle, exposure settings, location, environmental conditions and processing history—is often unavailable.
* **Too few independent measurements.** A single photograph or video rarely provides enough information to calculate an object's size, distance, speed or trajectory reliably.
* **Limited baseline data.** Investigators frequently lack comparable observations showing what the same sensor normally records under similar conditions, making unusual images difficult to interpret.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://smd-cms.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: smd-cms.nasa.gov">[nasa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">smd-cms.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

</div>

NASA noted that even reports accompanied by photographs or videos may remain impossible to evaluate if these supporting details are absent. A dramatic image alone does not necessarily provide enough information for scientific analysis because the context in which it was recorded may be unknown.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://smd-cms.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: smd-cms.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">smd-cms.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

An important consequence is that some apparent anomalies have later been explained as sensor artefacts once calibration records and metadata became available. This demonstrates why NASA places as much importance on documenting the observing instrument as on the object being observed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report-0.pdf?emrc=692cf3e8a28a7" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">uap independent study team final report 0</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

## Why eyewitness testimony alone rarely settles origin

NASA's report does not dismiss eyewitnesses. Instead, it distinguishes between sincere observations and evidence that can establish what was actually observed. People may accurately describe what they experienced while still lacking the information necessary to determine an object's identity or physical characteristics.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

Human observation has several well-known limitations relevant to aerial events:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* Distance and scale are often difficult to judge against an empty sky.
* Speed and altitude can be misperceived without fixed reference points.
* Brief observations provide little opportunity for careful measurement.
* Memory may become less reliable as time passes or after repeated retelling.

</div>

Because of these limitations, eyewitness reports become much stronger when supported by independent evidence such as radar tracks, multiple synchronised cameras, satellite observations or calibrated scientific instruments. NASA therefore treats witness accounts as potentially valuable starting points rather than definitive proof of an object's origin.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

This approach also explains why [unresolved reports]({{ 'unresolved-reports/' | relative_url }}) should not be interpreted as evidence supporting extraordinary claims. If the available information cannot reliably determine whether an object was a balloon, aircraft, atmospheric phenomenon or something genuinely unusual, it also cannot justify concluding that it represents extraterrestrial technology.

## What better UAP data collection would require

Rather than attempting to explain every historical sighting, NASA's study concentrated on improving future observations. The report recommends building datasets that allow competing explanations to be tested scientifically instead of relying on isolated anecdotes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA ScienceFebruary 23, 2026...</span><span class="citation-popover-meta">Published: February 23, 2026</span></span></span>

Key improvements include:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **Standardised sensor calibration** so measurements from different instruments can be compared reliably.
* **Complete metadata collection** recording precisely how, when and where observations were made.
* **Multiple independent sensors** observing the same event simultaneously, allowing triangulation of position, speed and motion.
* **Multispectral observations**, including visible, infrared and other wavelengths where appropriate, to provide more physical information about observed objects.
* **Rapid sharing of observations** so transient events can be examined using multiple datasets before they disappear.
* **Advanced analytical methods**, including machine learning, to identify rare events while filtering ordinary aircraft, satellites and atmospheric phenomena from extremely large observational datasets.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report-0.pdf?emrc=692cf3e8a28a7" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">uap independent study team final report 0</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

## Why these findings matter when evaluating unresolved UFO reports

NASA's conclusions reinforce an important distinction within discussions of failed UFO predictions. An unresolved UAP report usually reflects missing or inadequate evidence, not hidden confirmation of an extraordinary explanation. When calibration records, metadata and independent measurements are absent, investigators may honestly conclude that a case cannot presently be identified. That outcome represents uncertainty, not validation of any particular hypothesis.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science NASA</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA Independent...</span></span></span>

The study therefore frames many [unresolved cases]({{ 'unresolved-cases/' | relative_url }}) as a data-quality problem rather than an evidence-of-aliens problem. Improving future observations—not interpreting incomplete evidence more confidently—is presented as the scientific path towards resolving more cases. Until such higher-quality datasets exist, NASA's position is that the available evidence remains insufficient to draw firm conclusions about the nature or origin of many reported UAP.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/news-release/update-nasa-shares-uap-independent-study-report-names-director/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">UPDATE: NASA Shares UAP Independent Study Report; Names Director</span><span class="citation-popover-snippet">UPDATE: NASA Shares UAP Independent Study Report; Names Director - NASA...</span></span></span>

    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
